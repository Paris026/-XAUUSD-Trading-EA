# XAUUSD-Trading-EA

MT4上で動作する、GOLDmicro（XAUUSD）向けの自動売買EAです。

## 概要

GOLDの値動きを対象に、ナンピン・ヘッジ・ATRを利用した自動売買ロジックを実装しました。

実際にMT4上で動作確認や検証を行い、相場のボラティリティや含み損の増加など、運用時に発生する課題を確認しながら機能の追加・改善を行っています。

## 主な機能

- MT4での自動売買
- GOLDmicro（XAUUSD）対応
- ナンピンロジック
- ヘッジ機能
- ATRを利用したボラティリティ判定
- 相場状況に応じたナンピン幅の調整
- 一括決済ボタン
- 含み損の確認機能
- 利確条件や取引条件のパラメータ設定

## 開発で工夫した点

### 1. 小さい取引単位で検証できるように設計

資金に対するリスクや含み損を抑えながら検証するため、GOLDmicroを使用しています。

利用している取引環境では、MT4でGOLDmicroを利用することで通常のGOLDよりも小さい取引単位から運用できるため、MT4を採用しました。

### 2. ボラティリティに応じたナンピン幅の調整

GOLDは短時間で大きく価格が変動する場合があります。

ボラティリティが高い状態で連続してナンピンを行うと、短時間でポジション数が増え、含み損が大きくなる可能性があります。

そのためATRを利用して相場の過熱度を判定し、値動きが大きい場合には通常よりナンピン幅を広げる仕組みを取り入れました。

### 3. 一括決済ボタンの実装

MT4の標準画面では、保有している対象ポジションをワンクリックで一括決済する機能が十分ではないため、チャート上に独自の一括決済ボタンを配置しました。

相場が急変した場合などに、複数のポジションを素早く決済できるようにしています。

### 4. 含み損を確認できる機能

EAのリスクを検証するため、利益だけではなく含み損も確認できるようにしました。

稼働中の含み損を確認し、EAを停止した際にも検証に利用できるよう表示することで、設定変更前後のリスクを比較しやすくしています。

### 5. 実際の動作を確認しながら改善

EAを作成して終了するのではなく、

- エントリーが正常に行われるか
- ナンピンの間隔が適切か
- 急激な値動きで含み損がどの程度増えるか
- ボラティリティが高い場面でどのような挙動をするか

などを実際に検証し、問題点を見つけるたびにロジックやパラメータを修正しています。

## 開発方法

AIをプログラミング支援ツールとして活用しながら、自分で売買ロジックや必要な機能を考え、仕様を決定しました。

その後、MQL4での実装、MT4での動作確認、テスト、問題点の分析、仕様変更を繰り返して開発しています。

特に「実際に動かした結果から課題を発見し、その課題を解決する機能を追加する」ことを意識して開発しました。
